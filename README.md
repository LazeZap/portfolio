# Retro RPG Portfolio — GitHub Pages

A small, responsive, amber-toned retro RPG portfolio made with plain HTML, CSS, and JavaScript. No build tools or paid domain required.

## Preview locally
1. Extract this folder.
2. Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Create a GitHub repository named `YOUR-USERNAME.github.io` (replace with your actual GitHub username).
2. Upload `index.html`, `style.css`, and `script.js` to the repository's root.
3. Open the repository's **Settings → Pages**.
4. Under the build/deployment source, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for deployment. Your site should be at `https://YOUR-USERNAME.github.io`.

## Personalize before publishing
Search `index.html` for these sample values and replace them:
- `PLAYER ONE` / `YOUR NAME`
- About-me paragraph and education details
- Example project descriptions, statuses, and repository URLs
- Skills and achievements (keep them accurate)
- `yourname@example.com`
- GitHub and LinkedIn profile links
- Update `title` and meta description if you like

The sample GitHub project buttons intentionally point to the generic GitHub homepage; replace each with the actual repository URL.

## Controls
- Click **Start Adventure** or press Enter at the title screen.
- Use arrow keys to move focus through the menu; press Enter to open a section.
- Press `1`–`7` to jump directly to a section.
- Press Escape to return to the title screen.
- Optional synthesized click sounds are off by default.
- Try the classic arrow-key sequence shown in Extras for a small Easter egg.

## Notes
- This is a static website and works on GitHub Pages.
- The Google Fonts import is optional; if unavailable, fallback fonts are used.
- No analytics, server, or form backend is included. Contact uses a `mailto:` link.
